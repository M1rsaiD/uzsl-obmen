5. **Угрозы.**

## U20. Сильное сглаживание меток; взвешенная CE (вместе с к2)
1. **Механизм.**
   - Цель (1 − α)·one-hot + α/K.
   - CE с повышенным весом для плохо распознаваемых классов и похожих пар, как в [GISLR-2].
2. **Какую ошибку устраняет.**
   - Самоуверенность на редких классах (корзины 1 и 2–4: 67 % теста).
   - Путаницу похожих жестов (54,6 % ошибок — пары, близкие и по форме, и по месту).
3. **Доказательства.**
   - [GISLR-2]: сглаживание подбиралось Optuna в диапазоне **0,5–0,7** (необычно сильное), веса классов — в степенях 0,75–2. Отдельного вклада нет. Проверено по первоисточнику.
   - [Müller 2019]:
     - сглаживание стягивает представления класса в плотные равноудалённые кластеры;
     - улучшает калибровку;
     - точность меняется мало: табл. 2 — CIFAR-100/ResNet-56 72,1 ± 0,3 → 72,7 ± 0,3 при α = 0,1; ImageNet/Inception-v4 80,9 → 80,9;
     - **ухудшает дистилляцию**: учитель со сглаживанием даёт худшего ученика, потому что в логитах стирается информация о сходстве классов (разд. 4).

     Проверено по полному тексту.
4. **Где выигрыш.** Корзины 1 и 2–4. **Оценки величины нет.** Прирост — только от смены значения α относительно рецепта Sohn (вопрос к2).
5. **Угрозы.**
   - Веса «трудных» классов подбирать только по V_k: по тесту — утечка.
   - При 3 531 классе α = 0,5–0,7 даёт очень слабую цель для частых классов, и они могут просесть.
6. **Проверка.** V_k, два значения α (рецепт Sohn и 0,5) — ≈ 2 × 8 ч. Взвешенная CE — отдельной строкой.
7. **Взаимодействия.**
   - **U29 (дистилляция):** по [Müller 2019] сильное сглаживание учителя вредит ученику — не совмещать без проверки.
   - **U13 (прототипы):** плотные кластеры меняют геометрию эмбеддингов. Проверять U13 с тем α, который будет в итоге.
   - U22: оба приёма перекашивают решение к редким классам.

## U24. Шумные метки: вес по надёжности источника, OUSM, co-teaching (вместе с к3, к2)

   Моя оценка доли ошибочных меток в обучении — порядка 2 %, грубо и без ДИ. Основной «шум» у нас другой: дубли латиница/кириллица и синонимы (2,2 % ошибок и ≈ 6 из 30 главных пар, [диагн.]). Его лечит U23 (к3), а не U24.

## U26. Самообучение на неразмеченных точках (вместе с к2)
1. **Механизм.** Предобучение кодировщика восстановлением замаскированных точек (суставы, кадры, отрезки) на неразмеченных клипах, затем дообучение на метках, как в [SignBERT+].
2. **Какую ошибку устраняет.** Нехватку размеченных примеров (67 % теста — классы с ≤ 4 записями): кодировщик заранее учит «грамматику» движений кисти.
3. **Доказательства.** [SignBERT+], проверено по полному тексту:
   - табл. 11, MSASL (1 000 классов), top-1 по записям: без предобучения 53,31 % → самообучение на всех данных (≈ 230 тыс. видео) 62,42 % (+9,1 п. п.); WLASL: 38,33 → 48,85 (+10,5);
   - на тех же данных (≈ 160 тыс. видео) учительское предобучение даёт 58,82 %, самообучение — 60,13 % (+1,3 к учительскому).
4. **Где выигрыш.** Корзины 1 и 2–4. У нас уже есть учительское предобучение на РЖЯ (+14,7, к3 № 27). Сравнивать надо с ним, а по [SignBERT+] самообучение поверх «учительского на тех же данных» — порядка +1 п. п. **Оценки для нас нет.** Объём неразмеченных клипов УзЖЯ — **нет данных** (вопрос к2).
5. **Угрозы.**
   - Масштаб: у [SignBERT+] сотни тысяч видео.
   - Их декодер учитывает модель кисти; простое маскирование может дать меньше.
   - Цена — ≥ 24 ч ГП.
6. **Проверка.** Только после дешёвых идей и если неразмеченных клипов ≥ десятков тысяч. Тогда — отдельная серия с предрегистрацией.
7. **Взаимодействия.** U34 (то же предобучение во всех ветках) — самообучение добавляется **поверх** РЖЯ, сравнение при одинаковом РЖЯ. U25.

## U28. Ансамбль по логитам; отражение и сдвиг при выводе (вместе с к2)
1. **Механизм.**

   - При выводе — исходная запись, отражённая и сдвинутая по времени; ответы усреднить.
2. **Какую ошибку устраняет.** Дисперсию одиночной модели (разброс затравок) во всех корзинах.
3. **Доказательства.**

   - [GISLR-2]: ансамбль без softmax «устойчиво давал ≈ +0,01» на LB против усреднения вероятностей. Проверено по первоисточнику.

4. **Где выигрыш.** Все корзины. Для телефона: модель занимает < 0,4 % задержки (0106), поэтому три модели добавляют ≈ 8 мс к ≈ 2,5 с записи.

7. **Взаимодействия.** U06, U29 (дистилляция ансамбля в одну модель — к3).

## U22. Поправка логитов на частоту класса — **снять** (кратко)
По [Menon 2021] (проверено по полному тексту) поправка f_y(x) − τ·log π_y по построению оптимизирует **сбалансированную ошибку** — среднее ошибок по классам (уравнения 2, 8, 9). Наша метрика другая: top-1 по записям, macro по исполнителям. При LOSO частоты классов в тесте близки к обучающим, поэтому сдвиг к редким классам меняет точность частых на точность редких. Итог измерен: **τ = 1 → −3,7 п. п.** ([диагн.]). Подбор τ на V_k, скорее всего, даст τ ≈ 0. Снять как способ поднять основную метрику. Оставить можно только строкой для сбалансированной точности, если её будем приводить.
