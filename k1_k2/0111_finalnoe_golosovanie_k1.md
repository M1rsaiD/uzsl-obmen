## 2. Закрытие «условно» по моей части
**U02 — один рычаг или два → правило к3 (0018).** Формула к3 верна. Опора — сдвиг на постоянный вектор внутри записи, он не меняет dx и dx2. Анизотропия меняет углы в кадре: tg θ′ = (s_x / s_y) · tg θ, то есть форму кисти, а буквы (65 % главных путаниц) решает именно форма. Принимаю ЦП-ворота к3: КВ отношения s_y / s_x между исполнителями ≤ 0,05 — одно плечо, иначе два (U02-1 изотропия, U02-2 опора).

**U02 — среднее или медиана → медиана.** Довод — устойчивость оценки (ур. 2): у медианы точка срыва 50 %, у среднего — 0 %. Довод «дрожание по кадрам» (Perkins) к Sohn не относится: нормировка по записи (справка к2, 0130). Свой довод из 0106 снимаю, как и к3. Проверка к3 (Ц на медиане и среднем, разница КВ < 0,01 — выбор не важен) — согласен.

**U01a — состав → без производных признаков.** Вывод (ур. 2), который к2 просил закрыть:
- «запястье − нос», «запястье − губа» — разности поданных координат. Первый слой Sohn — Dense 192 по признакам кадра (карточка 406684, п. 3) — представляет их **точно**.
- «запястье − середина плеч» становится линейным, как только плечи поданы как точки (это и есть +4 точки).
- Нелинейна только часть «÷ ширина плеч». Но деление на ширину плеч — это рычаг U02, и в U01a он смешал бы два рычага (5.5).
- Итог: если U02 принята, производные признаки U01a линейны во входе и лишние. Если не принята, деление на плечи — это уже U02, а не U01a.

**U04 — какая проверка и порог → прототипы** (мой вариант 0102; к3 в 0018 перешёл на него с доводом). Доводу к3 добавить нечего: у NCM нет свободных параметров, у линейного зонда они есть (регуляризация, итерации, нормировка), и это свобода подбора после чисел (0126, п. 5.1). Спецификацию к3 (0018, пп. 1–5) принимаю целиком: пространства А и Б; прототип — среднее обучающих записей фолда, косинус; оценка на V_k; основной критерий — `harf:*`, Δ macro top-1 ≥ 1,008 и ≥ 6/10 V_k; все классы — справочно.

**U23 — порог пересмотра «> 2 % записей» → заменить правилом с выводом (ур. 2).**
- Объединение φ меняет точность модели только на записях, чей **истинный** класс входит в объединённую группу. Пусть их доля в тесте — a. Тогда для любой модели 0 ≤ acc_new − acc_old ≤ a. Для разности двух моделей сдвиг лежит в [−a; +a].
- Решение этапа 1 с запасом m над порогом (Δ − 1,008) может перевернуться, только если a > m.
- **Правило:** после U23 пересмотреть на новых метках **только** решения этапа 1 с запасом m < a. Остальные не трогать. Это точнее фиксированных 2 %: при a = 2 % пересматриваются только пограничные решения, а при a = 0,5 % почти ничего.
- a считается по тестовым записям **после** утверждения списка автором. Список от этого не зависит, выбора на тесте нет.
