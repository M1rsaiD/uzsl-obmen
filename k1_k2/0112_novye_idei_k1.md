## А. N1 — SHuBERT как готовый кодировщик

**Идея.** Замороженные признаки SHuBERT + линейная голова → при успехе LoRA ранга 1. Главная строка — ансамбль с Sohn.

**Какую слабость закрывает.** П. 1(а) — готовый предобученный кодировщик; п. 2 — другой вход: вырезы кистей и лица.

**Лучший вариант 2024–2026.**
- Источник: Gueuwou и др., SHuBERT, ACL 2025. Диск: `…/03-sign-language/methods/2025_gueuwou_shubert.pdf`, id 1d_xijhmjOSvT8j9tdG7pfJ91k4SxNzl0.
- Число, стр. 8, табл. 2 (ASL Citizen, Rec@1):

  | модель | Rec@1 | обучаемых параметров |
  |---|---|---|
  | SHuBERT, LoRA ранга 1 | **0,65** | 0,17 млн |
  | I3D | 0,63 | — |
  | ST-GCN | 0,60 | 0,45 млн |

  WLASL2000 P-I: SHuBERT 60,90 против Uni-Sign 63,52.
- Рецепт, стр. 8, разд. 4.3:
  - среднее по времени → BN → линейный слой;
  - LoRA ранга 1 на каждом линейном слое, остальное заморожено;
  - Adam 1e-4, weight decay 1e-4, 125 эпох, пакет 128;
  - lr LoRA = 1/10 от lr головы; сглаживание меток 0,1.
- Почему SHuBERT, а не другой кодировщик:
  - среди открытых весов с входом MediaPipe это единственный набор под MIT. Карточка `04_База_знаний/06_Исследование_архитектуры_(18.10.2026)/Новые_находки_из_интернета/N3_Веса_Uni-Sign_и_SHuBERT…md`, id 102Boc_DYL_1ZBmz2x7aSBNm_jGumFktj;
  - у Uni-Sign лицензия CC BY-NC и вход RTMPose, а не MediaPipe (та же карточка).
- **Новее не найдено.** Искал на Диске («SHuBERT», «Uni-Sign», карточка N3) и в интернете: «ASL Citizen pose 2025». Нашлась только Perkins 2025 (100 глосс — уже разобрана, 0108).

- Дообучение — УзЖЯ. Какую артикуляцию используют наши исполнители, узбекскую или русскую, — нет данных.

**Лучший вариант 2024–2026.**
- Источник: Vandendriessche и др., arXiv:2502.20171, 2025. Диск: `…/Статьи и обзоры 2017–2026/ЖЯ — статьи, которых нет в dissertatsiya-library/2025_vandendriessche_one_shot_islr.pdf`, id 1VK0aQSUOUNJcevNKlTbg63Fuukbc0FYK.
- Стр. 6, разд. 3.3:
  - для переноса между языками взяты только поза и кисти;
  - модели с точками рта при one-shot «were worse». **Числа нет**;
  - причина по авторам: артикуляция специфична для языка.
- Их результат переноса (аннотация): one-shot MRR 50,8 % на словаре из 10 235 жестов другого языка.
- Новее с измерением «рот при межъязыковом переносе» — не нашёл. Искал на Диске («mouth», «mouthing»; карточки Uni-Sign и SHuBERT).

**Условия.**
- У них: MediaPipe; предобучение ASL Citizen → поиск по словарю (VGT, AUTSL, WLASL), а не дообучение классификатора.
- У нас: MediaPipe; РЖЯ → дообучение на УзЖЯ.

**Уровень довода «за»: 5** — препринт, сверен по первоисточнику, но **качественный**. Поэтому сначала ворота на ЦП.

**Почему маскировать только в предобучении, а не убрать губы совсем.**
- Контрдовод уровня 4 — Uni-Sign, ICLR 2025. Диск: `…/03-sign-language/methods/2025_li_uni_sign.pdf`, id 1DwXw7QYHQPKEPDtNxCZn55rxroB1CnRk.
- Стр. 16, табл. 13: на MSASL1000, только позы, с нуля, один язык, лицо даёт **+1,89 P-I** (41,56 → 43,45).
- Внутри языка лицо помогает, поэтому N2 сохраняет губы в дообучении на УзЖЯ и снимает только чужую артикуляцию.

**Атака на себя**

1. **(ур. 4) Uni-Sign, табл. 13.**
   - Губы в Slovo несут не только артикуляцию, но и немануальные жесты рта, которые могут переноситься.
   - *Проверка:* только сам опыт; ворота ниже отсекают случай, когда губы не важны.
2. **(ур. 2, вывод) Губы в дообучении начнут со случайных весов.**
   - При нулевом входе градиент по столбцам губ первого Dense равен x·δ = 0. Эти веса останутся случайными с инициализации, а остальной вход будет предобучен.
   - *Решение — часть определения N2, не второй рычаг:* перед дообучением обнулить столбцы губ, чтобы губы входили «без сигнала», а не шумом. Проверить в коде.
3. **(ур. 2) Буквы.**
   - 65 % главных путаниц — буквы и цифры; исполнители могут проговаривать название буквы.
   - Губы в дообучении остаются, поэтому довод касается только предобучения.
   - *Проверка:* на V_k отдельно `harf:*`.
4. **(правило 5.5) Предобучение внутри пары разное.**
   - Рычаг здесь и есть предобучение, как у U25. Вывод — только «предобучение без губ против с губами», всё остальное одинаково.

**Ворота до ГП (только вывод, ≤ 0,5 ГП-ч).** Проверка закрытием губ: губы подаются как пропуск, так же как порт обрабатывает пропавшие точки.
- (а) Модель, предобученная на Slovo: Δ на валидации Slovo.
- (б) Sohn ALL-UZ: Δ на V_k — общий, `harf:*` и слова отдельно.

Если в (а) Δ < 1 п. п., представление предобучения на губы не опирается и тратить ГП на N2 незачем — **снять**. Если Δ велико — ставить.

**Цена**
- Предобучение без губ: ≤ 10–15 ГП-ч (оценка к2 для U25, где записей больше; `UZSOHN_ideas_obosnovanie_v2.md`, строка 842).
- Отбор на 10 V_k: 6,7 ГП-ч (измерение к2).
- Итого ≈ 17–22 ГП-ч; ворота ≤ 0,5.
