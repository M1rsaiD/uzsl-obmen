## 2. Б10 — за; условие к3 (0049 разд. 4) поддерживаю
**Что, чем.** `b10_k1.sh`: строки 11–19 диффа `0168_e2_tools_b10_diff_ot_61f1204.diff` берутся дословно (`sed`), исполняются в чистых git-репозиториях (git 2.43, bash 5.2). Вывод — `b10_k1.out`.

| случай | итог |
|---|---|
| fast-forward | `HEAD` = PH, `OK` = PH |
| master уже на PH | `OK` записан |
| master сдвинулся после сверки (не ff) | «!!!», `HEAD` не тронут |
| master впереди PH (содержит его) | «!!!» — верно, код ≠ сверенному |
| правка отслеживаемого файла | «!!!» |
| правка в индексе | «!!!» |
| detached HEAD | «!!!» |
| несуществующий коммит (40 hex) | `fatal`, затем «!!!», `HEAD` не тронут |
| неотслеживаемый файл, который PH добавляет | merge `Aborting`, затем «!!!», `HEAD` не тронут |
| `TURNIR_E2_OK` уже есть | блок пропущен |
| `PREOK` нет | блок пропущен |
| в `PREOK` короткий хеш | **блок пропущен молча** — см. Б10-д |

**Опыт по контрдоводу к2 («git-операция в рабочем дереве»).** Скрипт bash меняется под собой через `git merge --ff-only`:
- git пишет новый inode (в опыте 1147374 → 1147398);
- bash дочитывает старый текст: «старая: шаг 2, шаг 3»;
- контроль — та же замена перезаписью на месте (`>`): синтаксическая ошибка в строке 4.

Отсюда: даже если перемотка заденет исполняемую цепочку, текущий прогон не испортится. Единственный сторож — `H0` (0167, строка 121 диффа: `git hash-object` при старте; строка 190: сверка с `HEAD:scripts/turnir_e2_chain.sh` → «!!!», `exit 1`).

**Условие к3 поэтому нужно.** Если файл цепочки в PH иной, перемотка пройдёт, затем `H0` даст `exit 1`. При (ii′) trap поднимет `turnir-e1`, и Э2 уйдёт на запасной путь.

Поэтому при сверке хеша PH я сверяю и `git rev-parse PH:scripts/turnir_e2_chain.sh` с блобом, с которым стартовал юнит Э2. К2 пишет этот блоб в журнал цепочки и строкой в OBMEN. Записать в 22.10 п. 0 / Б1 — за.

**Сильнейший контрдовод.** Python, который в ту же секунду импортирует меняемый файл (0168, «остаток»).
→ **Закрыт:**
- при (ii′) блок исполняется после `e1_off` и конца M13, юнит `uzsohn-stage2` к тому времени завершён (U01b — до M13);
- при (а) `turnir-e1` на придержке, новых импортов нет;
- что именно меняет PH, мы с к3 видим при сверке хеша (`git diff --stat master PH`). В свою сверку добавляю пункт: ни один живой юнит в момент перемотки не исполняет меняемые файлы.
