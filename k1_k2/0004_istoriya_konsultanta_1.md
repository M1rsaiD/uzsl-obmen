## 3. Почему решено так (то, что легко истолковать иначе)

1. **Протокол П (SD-5).** Исполнители не пересекаются; 6 «тяжёлых» исполнителей Slovo всегда в обучении; «лучше/хуже» — только если 95 % ДИ парной разности по исполнителям не содержит 0. На пилоте — только постоянство знака в 6 парах.
2. **Пилот.** Бюджеты фиксированы заранее, последний шаг, train ∪ val на «все». Подбирать что-либо на пилоте нельзя.
3. **A1, а не A2, в статье 1.** A2 найден по тесту. В статье он — облегчённый вариант (в 3,9 раза меньше GFLOPs), с валидацией и переносом (M9.2b). Для системы диссертации выбор A1/A2 — после M9.4 (устойчивость).
4. **Граф в новизну не заявляется.** Новизна архитектуры — токены частей тела с двумя системами координат.
5. **Ёмкость.** A1-большая — кандидат в позовую ветвь учителя Э6 только для словаря (Slovo).
6. **Корпус v2.** Числа корпуса не публикуются до проверки меток человеком и письменного заключения юриста. Тест LOSO — только записи с проверенной меткой.
7. **Н3.** Калибровка по Мондриану не даёт гарантии для нового исполнителя — только HCP (для зарегистрированного — GHCP). Формулировка новизны узкая: «конформный отказ для изолированных жестов ЖЯ по ключевым точкам с гарантией для нового исполнителя».
