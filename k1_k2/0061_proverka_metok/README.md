# Страница проверки меток корпуса УзЖЯ (консультант_1, 05.11.2026)

Автор не знает УзЖЯ, поэтому вопрос «верна ли подпись» ему не задаём. Вместо этого он сравнивает два видео: **сегмент корпуса** и **эталон того же слова из словаря imo-ishora**, и отвечает: «тот же жест / другой / не уверен / нет эталона».

Страница — один файл `proverka_metok.html`. Работает без интернета, ничего не загружает и не отправляет: видео открываются из выбранной папки на самом ПК.

## Что подготовить (консультант_2, на лабораторном ПК)
1. **Выборка.** `data/review_sample_v1.json` (300 записей теста LOSO, затравка закоммичена) — та же, что предрегистрирована.
2. **Эталон.** Для каждой записи — видео imo-ishora с тем же словом после нормализации написания. Нормализация та же, что для корпуса; правило сопоставления закоммитить до показа автору.
   - Нет эталона — `"b": null`.
   - Несколько эталонов — взять первый по заранее заданному правилу; остальные перечислить в поле `"b_alt"` (справочно).
3. **Папка с видео** — один корень, внутри любые подпапки. Пути в списке — относительно этого корня.
   - Сегменты можно не вырезать: указать урок и `start` / `end` в секундах.
   - Страница повторяет отрезок по кругу.
4. **Список пар** `manifest_review_v1.json`:
```json
{"version": "review_v1, коммит …",
 "pairs": [
  {"id": "S03_000123", "gloss": "salom",
   "a": {"path": "korpus/C02/lesson_017.mp4", "start": 412.4, "end": 414.1},
   "b": {"path": "imo-ishora/salom.mp4"}},
  {"id": "S07_000456", "gloss": "kitob", "a": {"path": "korpus/C05/lesson_003.mp4", "start": 88.0, "end": 89.6}, "b": null}
 ]}
```
   - `id` уникальны. Порядок пар перемешать с закоммиченной затравкой.
   - Предсказаний модели в списке нет: проверка слепая.

## Как работает автор
1. Открыть `proverka_metok.html` в Chrome или Firefox на ПК.
2. Кнопка «1. Список пар» — выбрать `manifest_review_v1.json`; кнопка «2. Папка с видео» — выбрать корень.
3. Клавиши: `1` тот же жест, `2` другой, `3` не уверен, `4` нет эталона, `←`/`→` — назад и вперёд, пробел — повторить оба видео. Кнопки «0,5×» замедляют; «Отразить» — если исполнитель левша.
4. Ответы сохраняются в браузере сами. Кроме того, раз в 30–50 пар нажимать «Сохранить ответы в файл» → `answers_v1.json`.
   - Продолжить на следующий день: выбрать список, папку и «Продолжить: загрузить ответы».

## Как считать (консультант_2)
- Точность меток — доля `same` среди пар с эталоном, с 95 % ДИ бутстрепом по исполнителям.
- Отдельно — доля `unsure` и `noref`.
- Записи `different` исключаются из теста, или их метки правятся по эталону. Правило — в предрегистрации до подсчёта.
- После этого — пересчёт LOSO без переобучения.

Проверено консультантом_1: загрузка списка и папки, повтор отрезка start–end, клавиши, комментарий, выгрузка `answers_v1.json`, сохранение ответов после перезагрузки.
Встроенный в Playwright Chromium не умеет H.264, поэтому проверка шла на WebM. Обычный Chrome и Firefox на ПК H.264 воспроизводят.
