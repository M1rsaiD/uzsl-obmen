# Формат сводной таблицы турнира `turnir_summary.csv` (консультант_1, 05.11.2026)

Одна строка — одна модель или один ансамбль на одном наборе при одном рецепте и одном условии. Кодировка UTF-8, разделитель — запятая, десятичная точка.

| столбец | значение |
|---|---|
| `dataset` | `Slovo`, `Bukva`, `UzSL` |
| `model` | `A1`, `A2`, `MPK_large`, `ST-GCN`, `SL-GCN`, `Sohn`, `UzSohn`, `E1`, `BiLSTM`, `hybrid_narrow`, …; для смешанного ансамбля — состав через «+» (`A1+SL-GCN+ST-GCN`) |
| `kind` | `single` — одиночная (среднее по затравкам); `ens_homo` — однородный ансамбль затравок; `ens_mixed` — смешанный |
| `members` | число моделей в ансамбле (1 для одиночной) |
| `recipe` | `native` (рецепт авторов) или `shared` (общий) |
| `condition` | `transfer` (Slovo + Bukva → УзЖЯ) или `scratch`; для Slovo и Bukva — `scratch` |
| `top1`, `top1_lo`, `top1_hi` | macro по исполнителям, %, и границы ДИ |
| `ci_level` | уровень ДИ, % (99 для главных строк) |
| `gflops` | ГФЛОП на окно при тесте; для ансамбля — сумма по членам |
| `latency_ms` | медиана 100 замеров на ЦП в одном сеансе; для ансамбля — сумма (последовательный вывод) |
| `params_m` | млн параметров для вывода; для ансамбля — сумма |
| `n_seeds` | число затравок |
| `source` | файл и коммит, откуда строка |

Неизвестное значение — пустая клетка или `нет данных`: точка не рисуется, строка не теряется.

Ансамбли считаются из сохранённых вероятностей тестовых записей:
- одинаково для всех — среднее вероятностей;
- состав смешанного ансамбля выбирается по валидации;
- веса не обучаются.

Рисунки:
- `python3 pareto_turnir.py turnir_summary.csv --out ris_turnir` — граница Парето по ГФЛОП;
- `--x latency_ms` — по задержке;
- `--recipe shared` и `--condition scratch` — другие срезы.
