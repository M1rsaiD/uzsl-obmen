# Статья 1 — рабочие файлы консультанта_3 (с 05.11.2026)

Итоговая статья 1 для *Journal of Automation and Intelligence* (KeAi/Elsevier). Статьи 2 нет — корпус, LOSO и внешние тесты входят сюда (решение автора 05.11.2026).

## Что где

- `src/en/*.md`, `src/ru/*.md` — текст статьи по разделам (Markdown + формулы LaTeX; `{{TABLE:…}}` и `{{FIG:…}}` — места таблиц и рисунков, которые генерирует сборка). Места, требующие решения или документа автора, помечены `⟦…⟧` (в PDF — красным).
- `src/refs_v2.json` — библиография (CSL-JSON, 41 запись).
- `tools/analyze.py` — **единственный источник чисел**: читает выгрузку `k2_k3/0001_article1_exports`, пишет `out/numbers.json` и рисунки `out/figures/`.
  Запуск: `python3 -I tools/analyze.py ../k2_k3/0001_article1_exports out` (≈ 35 с; pandas, numpy, matplotlib).
- `tools/build.py` — сборка статьи: `python3 -I tools/build.py en` / `ru` → `build/<lang>/main.tex`, `main.pdf` (шаблон KeAi `cas-dc`, latexmk), `article.docx` (pandoc + ieee.csl). Пути к рисункам статьи 1 из репозитория диссертации и к `ieee.csl` заданы в начале файла — поправить под свою машину.
- `tools/supp.py` — дополнительные материалы: `python3 -I tools/supp.py` → `build/supp/supp.pdf` + CSV по классам.
- `out/numbers.json`, `out/figures/` — результат `analyze.py` на выгрузке 0001 (05.11.2026).
- `figures_build/` — все рисунки в том виде, в каком они вошли в сборку (PDF + PNG).
- `versions/<версия>_<дата>/` — готовые файлы каждой версии: PDF и DOCX (EN, RU), дополнительные материалы, сопроводительное письмо, исходники LaTeX. Ничего не удалять и не перезаписывать — новая версия в новую папку.
