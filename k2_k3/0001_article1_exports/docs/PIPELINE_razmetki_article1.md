# Конвейер авторазметки YouTube-уроков УзЖЯ (для статьи 1; к3 0001, разд. 3 п. 2)

От: консультант_2, 05.11.2026. Сжатое описание по отчёту обработки уроков (27.10.2026) и паспорту корпуса; каналы — C01…C11,
исполнители — S01…S12, имена каналов и ведущих не приводятся. Код — `tools/` папки уроков (локально, вне git).

## 1. Точки
Экстрактор Э0: MediaPipe Holistic 1.1.1 (модель sha256 `e2dab611…`), без сети (`unshare -rn`), по процессу на урок; 0 ошибок
декодирования. Видео AV1 перед извлечением перекодируются в H.264 (CRF 16). Хранятся только 85 точек МПК (сырые x, y, z;
NaN — часть не найдена), `present [T,4]` (поза, левая кисть, правая кисть, лицо), видимость 6 точек позы, отметки времени.
Зеркало: OCR 8 кадров урока в исходном и отражённом виде (правило ≥ 3 слов и > 2×) → `unmirror: false` для всех уроков.

## 2. Нарезка
- *Слова* — «руки подняты»: запястье по позе выше уровня покоя (80-й перцентиль минимума высоты запястий − 0,4 ширины плеч),
  склейка пауз < 0,3 с, отброс сегментов < 0,4 с.
- *Дактиль и цифры* — удержания формы ведущей кисти внутри активных участков (скорость формы < 2 размеров кисти/с не менее
  0,32 с), соседние удержания одной формы склеиваются.
- Мелкий кадр, где ведущий не опускает руки (< 0,8 сегмента на надпись): сегмент = самый длинный участок с видимой кистью
  внутри интервала надписи.
- Всего 11 153 сегмента авто-нарезки (все каналы).

## 3. Подпись — три опоры
1. **Текст на экране** — OCR (tesseract `uzb`, для кириллических уроков `uzb+uzb_cyrl`), кадр каждые 0,5 с; отбрасываются
   логотипы и постоянные надписи (слова в ≥ 3 уроках), первые 10 с, строки > 3 слов (субтитры), многократно повторяемые строки;
   из кадра берётся самый крупный текст.
2. **Речь** — faster-whisper large-v3, `language=uz`, отметки слов: окно «Keyingi … → следующее Keyingi», слово объявления,
   повторённое в окне, сегмент в пределах 2 с от упоминания; перечни из 1–3 слов между знаками препинания.
3. **Порядок урока** — слово, повторённое подряд («bir, bir»), в пределах 2 с; в уроках дактиля — буква по выравниванию
   объявлений с алфавитом.
Названия видео как источник подписи не используются.

## 4. Проверка согласия опор (без человека)
Для каждого сегмента — независимые якоря: физика рук (длительность 0,4–4 с, кисти видны ≥ 60 %, покой ≥ 20 % в 0,5 с вокруг),
надпись OCR (одна, перекрывает ≥ 50 % сегмента), речь (похожее слово ≥ 0,72 по нормализованному ключу в ± 2,5 с), повтор
(DTW траекторий рук до сегмента с той же подписью ≤ 25-го перцентиля пар с разными подписями урока). *reliable* — подпись есть,
физика в норме и ≥ 2 якоря; *reject* — нет подписи / < 0,4 с / не знак; остальное — *suspicious*. Все suspicious и
стратифицированная выборка reliable просмотрены **моделью** (консультант_2) по отрисованным скелетам, шкале надписей/речи и
вырезу области текста (лица в вырез не допускаются); вердикт по границам и подписи; непригодные исключены.
Итог: 6 031 сегмент оставлен, 5 985 без дубликатов (повторно загруженные видео — корреляция траекторий запястий ≥ 0,9);
в корпус — 5 671 запись YouTube после исключения 314 фраз (2–3 знака в сегменте) + 322 записи пилота = 5 993.

Точность авторазметки по выборке reliable (вердикт модели, Wilson 95 %; два крупнейших канала C03 и C02, n = 94 и 206):
подпись верна 80,9 % [71,7; 87,5] и 87,4 % [82,1; 91,2]; границы и подпись верны вместе 81,7 % [76,9; 85,6] (оба, n = 300).
Это оценка модели, а не человека; слепая повторная проверка 44 сегментов той же моделью — согласие по подписи 84 % [71; 92].
**Человеческая проверка** (автор, 05.11.2026, 300 пар, по 30 на исполнителя-фолд): с эталоном словаря imo-ishora — 98,2 %
[94,4; 100] (113 пар); построчно — `docs/label_review_pairs.csv`, итог — `docs/LABEL_REVIEW_result_v1.md`.

## 5. Нормализация глосс (`gloss_norm`)
Нижний регистр; апострофы ʻ ’ ‘ ` ʼ → '; без пунктуации; узбекская кириллица → латиница (ў→o', ғ→g', қ→q, ҳ→h, е в начале и
после гласной → ye); русские подписи и слова речи → узбекская латиница по словарю `ru_uz.json` (953 записи, перевод моделью,
носителем не проверен); варианты написания (ключ h/x, q/k, двойные буквы; близкие ключи ≥ 0,92) → самая частая форма; буквы
дактиля — отдельно по алфавиту (`harf:а` кир. ≠ `harf:a` лат.). Итог по всем каналам: 3 669 сырых строк → 2 453 канонических.
Слияние синонимов и одинаковых букв лат./кир. (2 381 → 2 214 классов) отложено до проверки носителем.

## 6. Ограничения
Подписи — согласие надписи/речи/времени, а не узнанный знак; пороги якорей выбраны без отдельной проверочной выборки; у каждого
ведущего YouTube одна студия и камера (LOSO мерит «новый человек + новые условия съёмки»); совпадение ведущих между каналами и с
внешними тестами автором не проверено (C05 и C08 объединены в S07 по метаданным).
