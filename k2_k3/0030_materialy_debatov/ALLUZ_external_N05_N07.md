## Проверка дублей (письмо к1 0085, разд. 2.2; 07.11.2026)

Код — `scripts/alluz_external_dups.py`, выход — `ALLUZ_external_N05_N07_dups.json` (по записям). Только ЦП, кадры и лица не просматривались. Для каждой записи N05/N07 — ближайшая обучающая запись итоговых моделей (все 7 815 записей ALL-UZ) **того же класса**, три меры:
- **корр. (как N04 = C12, `scripts/n04n07/dups_short.py`, `451f2d6`)** — высоты запястий по полным точкам Э0 отрезка, активный участок → 32 отсчёта, Пирсон, среднее по 2 запястьям (+ максимум с перестановкой рук); по правилу `dups_short` запись с неподвижной кистью (std < 0,05) не сравнивается;
- **корр.-1** — то же, но только по подвижным запястьям (для одноручных знаков, иначе выпадает половина N05);
- **мера Б** — расстояние поз кистей (42 точки + запястья, в ширинах плеч, 32 кадра, медиана по кадрам; min с зеркалом) — для статичных знаков.

Порог дубля: корр. или корр.-1 ≥ 0,98 (как у N04); мера Б ≤ 0,086 — самая далёкая из известных пар дублей. **Калибровка на известных дублях** (записи C12 уроков 01–05 и те же моменты в N04 02–06, 32 пары): корр. медиана 0,991 [0,906; 0,999], ≥ 0,98 — 17 из 23 (порог ловит ≈ 3/4 копий; 23, а не 32: у 9 пар хотя бы в одной записи одна из кистей неподвижна (std высоты < 0,05), и по правилу `dups_short` корреляция по двум запястьям к ним не применяется; корр.-1 по подвижным запястьям применима ко всем 32, ≥ 0,98 — 25 из 32); мера Б 0,019 [0,013; 0,086] — разделяет копии надёжнее.
