## 4. Почему А хуже шага 1 — **поисковый анализ задним числом, НЕ предрегистрирован**

Анализ придуман после того, как увидели §3 (А − шаг 1 < 0). Числа ниже — для толкования, не для выводов статьи.
Скрипт — вне git (рабочая папка консультанта_2), на тех же `predictions.csv`, без новых прогонов и без ГП.

**Приём.** Ответ модели А (Б) ограничивается классами головы шага 1 **того же фолда** (682 класса во всех 11 фолдах,
`runs/loso/<фолд>/seed0/labels.json`): ответ = первый класс из top-5, входящий в эти 682. Если в top-5 таких нет — ошибка.
Top-5 после ограничения посчитать нельзя (в `predictions.csv` только 5 ответов), поэтому — только top-1.

| | А | Б (справочно) |
|---|---|---|
| top-1 исходный (§2) | 26,2 | 14,0 |
| доля ответов top-1, уже входящих в 682 класса | 68,0 % | 59,1 % |
| доля записей, где в top-5 есть хотя бы один класс шага 1 | 98,7 % | 94,1 % |
| **top-1, ограничение 682 класса, macro (10 исп.)** | **30,9** [24,1; 38,0] | **16,4** [10,1; 24,6] |
| сравнение | шаг 1: 32,0 | Б1: 17,3 |
| парная разность (ограниченный − сравнение) | −1,1 [−2,3; +0,0], 2/10 > 0 | −1,0 [−2,8; +1,1], 3/10 > 0 |

По исполнителям, А с ограничением: S11 48,6, S12 42,4, S01 24,3, S02 20,7, S03 15,5, S04 18,1, S05 32,2, S07 26,6,
S08 44,6, S09 35,6.

**Толкование.**
1. Почти весь проигрыш А (−5,8 п.п.) уходит при ограничении ответа классами шага 1: остаётся −1,1 (верхняя граница ДИ
   +0,013 п.п., т. е. на грани нуля). Треть ответов А (32 %) — классы вне 682, все они на этом тесте заведомо неверны.
2. Значит, дополнительные видео (единичные и редкие классы) **не улучшили представление** для 682 классов — ни у А, ни
   у Б (Б с ограничением ≈ Б1). Падение даёт **≈ 1 700 лишних классов-отвлекателей** в голове.
3. Отвлекатели — во многом синонимы, написания и одинаковые формы: в частых ошибках А — `shapka → telpak`,
   `sosiska → sasiska`, латиница → кириллица одной формы (`o' → у`, `u → у`, `sh → ш`). Это довод за слияние классов —
   **только по списку, подтверждённому носителем** (ответ консультанта_1, п. 3.1), не по ошибкам модели.

**Частые ошибки** (истина → ответ, среднее число на затравку, все фолды; без ограничения):
- **А:** `g' → g` 4,7; `o' → у` (кир.) 4,7; `k → do'sting` 4,7; `e → x` 4,0; `u → у` (кир.) 4,0; `u → qayerga` 3,7;
  `x → h` 3,3; `blinchik → quymoq` 3,3; `sosiska → sasiska` 3,3; `shapka → telpak` 3,3; `sh → ш` 3,0.
  Буквы — без префикса `harf:`. Из 15 частых пар 4 — латиница/кириллица или написание одного слова, 1 — синоним.
- **Б:** `p → m` 4,7; `l → m` 4,0; `m → p` 4,0; `g' → g` 4,0; `sh → sizning` 3,7; `e → x` 3,7; `x → h` 3,7;
  `d → 2` (цифра) 3,3; `erkak → mazali` 3,3; `choy → mazali` 3,3. У Б ошибки — близкие формы кисти и «слова-магниты»
  (`mazali`), признак слабого представления, а не синонимов.
