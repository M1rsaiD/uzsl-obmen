Источник и правила — `data/HELDOUT_sources.md`, подготовка — `reports/HELDOUT_prep_2026-11-02.md`. Автор 02.11.2026 подтвердил: ведущие N01 взрослые. **Совпадение ведущих N01 с ведущими корпуса (S01–S12) — не проверено** (если совпадает — это не «новый человек», а только «новый источник»). N01 остаётся отложенным: в обучение, подбор, отбор классов и калибровку ни одной модели не входит.

**2. Тест.** Записи `datasets/heldout_surdoway/annotations_heldout.json` (191 запись, 191 класс, по 1 записи; метки — из названия видео, **человеком не проверены**, `verified=false`). Для модели — записи, чей `gloss_norm` есть в её голове: головы 682 — **93** записи, головы 2 381 — **150** (93 ⊂ 150). Ответ — по всей голове (без ограничения классами N01).

**3. Сегмент (главный).** Правило `datasets/heldout_surdoway/tools/n01_labels.py` (зафиксировано до оценки): от начала первого до конца последнего участка «руки подняты» (`segment.active`) ± 0,2 с; без участков — всё видео (2 видео). **Справочно** (не главный результат): второй участок «руки подняты» ± 0,2 с отдельно — только записи с ≥ 2 участками (178/191 видео с ровно 2 участками + 8 с 3 + 2 с 4; вероятно, жест показан дважды).

**4. Вывод.** Как тест в `mpk.train` (`infer`): T = 32 равномерных кадра сегмента, без аугментаций, доминант — нет, вход МПК (85 точек x, y), предобработка точек — как `uzv2.cache.lesson_arrays` (интерполяция пропусков по всему видео, float16), та же модель Holistic (sha256 проверяется). Устройство — ЦП (ГП занята цепочкой M11; на ЦП автокаст bfloat16, как на ГП). Скрипт — `scripts/eval_heldout_n01.py`.

**5. Метрики.** top-1, top-5 по записям; 95 % ДИ — процентильный бутстреп **по записям** (10 000 повторов, затравка 20261102). Исполнитель N01 один (по-видимому) → **ДИ по исполнителям невозможен**; ДИ отражает только выборку слов, не разброс между людьми. Сравнение с LOSO (macro по 10 исполнителям) — справочное: N01 = один «отложенный исполнитель» и одновременно новый источник; набор классов N01 — подмножество (по пересечению названий), не весь словарь.

**6. Парные разности** (на общих записях, бутстреп по записям, одинаковые индексы для обеих моделей): **В − шаг 1** (93 записи) и **А − Б** (150). Справочно: шаг 1 − А на 93 общих записях (у А голова больше — разность смешивает перенос и размер головы). Вывод «лучше/хуже» — только если 95 % ДИ не содержит 0; иначе «не установлено».

**7. Частые ошибки** — только агрегаты: повторяющиеся пары «истинный → ответ» (≥ 2 раз), самые частые ответы top-1. Покадровые данные и предсказания по записям — только на ПК (`datasets/heldout_surdoway/cache_eval/`).

**8. Не делается:** никакого обучения/дообучения/калибровки на N01; никаких изменений модели демо по итогам N01.

## 3. Ошибки и выводы

- Каждое слово N01 — одна запись, поэтому повторяющихся пар «истинный → ответ» нет. Частые ответы top-1 (главный сегмент): шаг 1 — siz (5), qiz bola (4), iltimos (4); В — kurtka (5), bobo, ayol, men (по 3); А — qiz bola (6), yana, nima, iltimos (по 4); Б — ishsiz (11), maslahatchi (5) — у Б заметный «магнит». Единственная запись дактиля (harf:u) — ошибка у всех моделей.
1. **Шаг 1 на N01 ≈ LOSO** (33,3 против 32,0 top-1; 53,8 против 52,0 top-5): оценка «≈ 32 % на новом человеке», показанная в демо, подтверждается на независимом источнике (с оговорками ниже).
2. **В − шаг 1:** top-1 одинаков; top-5 у В выше на 15 п. п. (ДИ > 0) — согласуется с LOSO, где у В был выигрыш top-5 на словах (+2,4); на N01 (почти только слова) он больше. Правило замены демо (нижняя граница ДИ top-1 > 0) не выполнено — демо не меняется.
3. **А − Б = +14,7 п. п. top-1** — перенос с русских наборов воспроизводится вне корпуса (LOSO: +12,2).
4. А и Б (голова 2 381) — на уровне или чуть ниже своих LOSO.

**Оговорки:** один исполнитель (ДИ только по словам); одна затравка итоговых моделей; метки — из названий видео, без проверки человеком; классы N01 — подмножество по совпадению названий (93/682, 150/2 381), не весь словарь; совпадение ведущих N01 с ведущими корпуса не проверено — если совпадает, это тест «новый источник», а не «новый человек»; лицензия YouTube стандартная — числа до публикации согласовать (юрист, разрешение канала).
