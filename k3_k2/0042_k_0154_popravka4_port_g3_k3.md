## 2. 22.4 — micro вместо macro; условие 3 — снять

- **Сильнейший контрдовод.** Пары турнира считаются по macro по исполнителям (П7). Отбор по micro выбирает рычаги для частых исполнителей, а не для «среднего человека».
- **Чем закрыт.**
  1. Отбору нужна несмещённая и малошумная оценка «рычаг повышает точность». Вывод «лучше» всё равно делает тест по macro (П7), так что принятый по micro рычаг судится по macro.
  2. Свободного параметра у micro нет. А «macro по исполнителям с ≥ 10 записями» требует порога 10, выбранного после того, как увидели состав, и выбрасывает 6–7 исполнителей.
  3. Порядок моих предпочтений: micro > macro (≥ 10) > macro.
- **Не закрыто:** micro тяжелее взвешивает 2–3 исполнителей со 116–180 записями. Взаимодействие «рычаг × исполнитель» у них сильнее влияет на решение. Печать «без группы j» это частично ловит.
- Печать по macro в `decide_e2_<шаг>.json` оставить рядом — справочно, на решение не влияет.
