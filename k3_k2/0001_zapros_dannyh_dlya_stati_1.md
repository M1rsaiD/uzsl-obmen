## 1. Формат

Папка `k2_k3/0001_article1_exports/` (или отдельный приватный репозиторий `uzsl-article1-data`), внутри:

```
manifest.csv                       одна строка на прогон (см. ниже)
<series>/<condition>/<fold>/seed<k>/predictions.csv.gz
<series>/<condition>/<fold>/seed<k>/metrics.json
<series>/<condition>/labels.json    список классов головы (порядок индексов)
cost/*.csv                         параметры, GFLOPs, задержка ЦП, размер ONNX/TFLite (Г2-4, Г3, M11-Б, M9.4)
qc/*.json                          hand_recall_pose, доля кадров с позой/лицом (Slovo, Bukva, пилот, корпус)
budgets/M7_budgets.json            бюджеты в эпохах
splits/                            только то, чего нет в публичном репозитории: uzsl_loso.json (с кодами S), пилотные фолды (коды P)
```

`manifest.csv`: `series, condition, dataset, protocol, fold, seed, recipe, init (scratch / pretrain source), window_T,
git_commit_model, git_commit_series, dirty, path`.

`predictions.csv` (gz), столбцы: `record_id, signer, true, pred1, pred2, pred3, pred4, pred5` (+ `p1…p5`, float16,
если сохранены — нужны для ансамблей и калибровки; если нет — не считать заново).

**Обезличивание (правило README п. 1):**
- Slovo, Bukva, asl-signs, официальный Slovo — публичные `attachment_id` / `user_id` / `sequence_id`;
- корпус УзЖЯ — `signer` = коды S01…S12, `record_id` = `S02_000123` (сквозной номер внутри исполнителя; таблица соответствия
  остаётся на ПК); канал в экспорт не выводится;
- пилот — `signer` = 001/002/003, `record_id` = `P002_0005`;
- внешние тесты N01 и imo-ishora — `signer` = N01 / IMO, `record_id` = сквозной номер; названия видео не выводятся;
- никаких видео, кадров, `*.npz`, весов.
